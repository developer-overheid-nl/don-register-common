# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## v0.4.0 - 13-10-2026
### Added
* Add the RFC 9457 detail member to problem.Problem, which the NL GOV API Design Rules 2.2 require; constructors derive it from the error details or the title, NewWithDetail sets it explicitly, and the 404/405 problem handlers now include it. Add NewMethodNotAllowed.

## v0.3.0 - 16-09-2026
### Added
* Add a reusable OAuth 2.0 client credentials HTTP client with automatic token renewal.

## v0.2.0 - 22-08-2026
### Added
* Voeg herbruikbare JSON-logging en adapters voor Gin, cron en GORM toe voor de DON register-applicaties.
### Changed
* Upgrade Go, Go module dependencies and GitHub Actions workflow versions, and expand unit test coverage above 80%.

## v0.1.0 - 24-06-2026
### Added
* Add the EUPL-1.2 license file to the package repository.
* Add shared register packages for problem responses, pagination, filtering, database, router and Typesense helpers.
