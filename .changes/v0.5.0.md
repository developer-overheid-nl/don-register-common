## v0.5.0 - 24-11-2026
### Added
* `FilterGroup` heeft een optioneel `showTop` voor de filtertypes `search-single-select` en `search-multi-select` (constanten `TypeSearchSingleSelect` en `TypeSearchMultiSelect`): hoeveel opties de frontend toont voordat de gebruiker zoekt of uitklapt. `Validate` accepteert `showTop` alleen bij die twee types en vanaf 1; het verouderde `search-select` hoort daar niet bij. `SortOptionsByCount` zet de opties met de meeste treffers bovenaan.
### Fixed
* Make SortFilterCounts deterministic for values that differ only in case; lowercase now sorts first instead of depending on map iteration order, which made TestCountByFieldUsesValueAsSortKeyWithoutLabels fail intermittently.
